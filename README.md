This project implements a user-based recommendation system using Java and Apache Mahout.
The system suggests products or content to users based on the preferences and ratings of similar users.

It uses collaborative filtering, which is one of the core techniques used in real-world platforms like Netflix and Amazon.

# Objectives

Build a working recommendation engine in Java

Understand collaborative filtering concepts

Learn how Apache Mahout handles recommendation logic

Use Maven for dependency management


# Technologies Used

Java

Apache Mahout (Taste API)

Maven

CSV dataset


# How the System Works

Reads user-item ratings from CSV file

Builds a DataModel using Apache Mahout

Computes similarity between users using Pearson Correlation

Selects nearest neighbors

Predicts ratings for unseen items

Recommends top-rated items


# How to Run the Project
Step 1: Compile the project : 

mvn compile

Step 2: Run the application : 

mvn exec:java

# Conclusion

This project demonstrates how collaborative filtering works in recommendation systems using Java and Apache Mahout.
It provides a solid foundation for understanding how real-world recommendation engines operate.
